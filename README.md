# Seoul Picked — Free GitHub Pages Website

This is a complete Jekyll website, designed for **https://seoulpicked.github.io**.

## Publish it (one-time GitHub access required)

1. Sign in to GitHub as `seoulpicked`.
2. Create a **public** repository named exactly `seoulpicked.github.io`.
3. Upload **the contents of this ZIP**, not the outer folder, into the repository root. Keep folders beginning with `_` intact.
4. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
5. Wait for the GitHub Pages build and visit https://seoulpicked.github.io. The first build can take a few minutes.

If GitHub reports a build error, check the Actions tab. GitHub Pages builds Jekyll by default for branch-based publishing.

## Add an article

Create `_posts/YYYY-MM-DD-article-slug.md` with front matter:

```yaml
---
layout: post
title: "Article title"
date: 2026-11-23
category: food # food, style, culture, travel
description: "Short summary for search results."
---

Your article here.
```

Commit the file. GitHub Pages automatically rebuilds the site without additional payment or API usage.

## Content workflow without API cost

Use `ARTICLE_PROMPT.md` with ChatGPT to draft English articles, then review source accuracy and save as Markdown posts. This is **assisted writing**, not unattended AI publishing. ChatGPT subscriptions do not include free OpenAI API calls.

## Before promotion

- Add real YouTube/TikTok links once provided.
- Confirm current travel facts and product claims.
- Set up Google Search Console after the site is live.
- Avoid copyrighted photos without permission.
- Add privacy policy and disclosure pages before collecting personal data or monetizing.
