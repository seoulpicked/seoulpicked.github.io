# Seoul Picked: article-writing prompt

Write one original, helpful English-language article for Seoul Picked, an independent guide to Korean food, style, pop culture and travel.

Topic: [TOPIC]
Category: [food/style/culture/travel]
Target reader: [AUDIENCE]

Requirements:
- 600–900 words only when the topic supports that length; avoid filler.
- Friendly, clear, non-hyped English, with an engaging headline and useful subheadings.
- No invented first-hand experiences, quotes, prices, dates, store openings, product performance or event schedules.
- Flag any fact needing current verification; cite official sources where available.
- Provide a concise SEO description and a suggested slug.
- Include a natural call to action for related Seoul Picked content, not a fabricated product offer.
- Return GitHub Pages Jekyll Markdown with YAML front matter: layout: post, title, date, category, description.
- Keep the draft unpublished until factual checks are complete.
